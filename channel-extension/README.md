# 카카오채널 수신 도우미 (시범 구현)

예진샘 관리자 페이지의 **카카오채널 CS관리 → 읽지 않은 카톡 첨삭 프로그램으로 전송** 버튼과 함께 사용합니다. 이 확장 기능은 카카오채널 1:1 채팅 화면을 읽기만 하며 답장, 읽음 처리 버튼, 상담 완료 버튼을 누르지 않습니다. 다만 채팅방을 열면 카카오가 자체적으로 읽음 상태를 바꿀 수 있습니다.

## 사용 조건

1. 이 폴더를 Chromium 계열 브라우저에서 압축해제 확장으로 설치합니다.
2. **같은 브라우저**에서 카카오비즈니스 채널과 예진샘 관리자 사이트에 로그인합니다.
3. 예진샘 CS관리 탭의 버튼을 누릅니다. 확장 기능이 읽지 않은 채팅 목록을 찾으면 관리자 서버에 먼저 기록한 뒤 하나씩 엽니다.
4. 구매자명과 첨삭권이 하나로 확인되는 학습지 사진은 `대기 목록`의 제출로 생성합니다. 사진 없음, CS, 피드백, 구매자명이나 교재 확인이 필요한 경우는 CS관리 탭에 남깁니다.

## 검증 상태

백엔드의 중복 방지, 구매자명 매칭, 형제자매 예외, CS 분류를 로컬 테스트로 확인했습니다. 2026-11-10 Arc에 설치해 실제 카카오 목록에서 읽지 않은 채팅 2건을 미리보기로 확인했고, 이미 읽은 채팅에서 사진 3장을 읽기 전용으로 추출했습니다. 격리된 로컬 예진샘 화면에서 학부모 피드백의 CS관리 탭 표시와 확인 완료도 확인했습니다. 운영 사이트 배포는 Railway `SUCCESS`, `/health` 응답, HTML 버튼 표시까지 확인했습니다. **실제 읽지 않은 채팅을 여는 전체 전송 흐름은 아직 검증되지 않았습니다.** 카카오 관리자 화면은 공개 DOM 계약이 없어 구조가 바뀌면 확장 기능을 수정해야 합니다.

## 범위

- 예진샘 사이트: `https://yejinsaem-production.up.railway.app/`
- 카카오채널: `https://business.kakao.com/space/998603/channel/_Dqixdn/chats`
- 관리자 비밀번호는 확장 기능으로 전달하거나 저장하지 않습니다. 사진 데이터는 확장에서 예진샘 페이지로 전달하고, 페이지가 기존 관리자 인증으로 API에 업로드합니다.
- 전송 실패와 전체 수집 실패는 CS관리 탭에 기록합니다. 네트워크가 완전히 끊기거나 관리자 인증이 불가능하면 화면에만 오류가 표시될 수 있습니다.
