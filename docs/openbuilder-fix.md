# 카카오 채널에서 사진이 관리자 페이지로 안 올 때

## 증상 (지금 겪는 경우)

채널에서 이렇게 답하면 **우리 서버가 아닌 오픈빌더 기본 블록**이 응답한 것입니다.

- 「제가 할 수 있는 일이 아니에요」
- 「이해하기 어려워요」
- 「생글방글 예진샘이 순차적으로 답변…」

우리 서버(`https://yejinsaem-production.up.railway.app/kakao/webhook`)가 받으면 예를 들어 이렇게 나옵니다.

- 「사전 등록된 휴대폰 번호를 입력해 주세요」
- 「등록 확인되었어요!」
- 「사진을 받았어요! 선생님이 곧 피드백을 드릴게요.」

**채팅창에 사진·「첨삭 받기」·「피드백」만내면 스킬 서버가 호출되지 않습니다.**  
오픈빌더 시나리오에서 **스킬(웹훅) 블록**으로 연결해야 합니다.

---

## 필수 체크리스트 (오픈빌더)

### 1. 스킬 URL

[챗봇 관리자센터](https://chatbot.kakao.com/) → **스킬** → Endpoint URL:

```text
https://yejinsaem-production.up.railway.app/kakao/webhook
```

- 저장 후 **배포**까지 해야 채널에 반영됩니다.

### 2. 채널 ↔ 봇 연결

- [카카오톡 채널 관리자센터](https://center-pf.kakao.com/) → **비즈니스 도구 → 채팅방 메뉴** → **OFF** (챗봇과 동시 사용 불가)
- 채널에 **생글방글** 오픈빌더 봇이 연결돼 있는지 확인

### 3. 사진 수신 블록 (가장 중요)

**일반 채팅에 사진만 붙여 넣는 것**은 스킬로 안 갈 수 있습니다. 아래 중 하나로 설계하세요.

| 방법 | 설정 |
|------|------|
| **권장** | 블록에 **이미지 보안전송** 플러그인(`@sys.plugin.secureimage`) 추가 → **스킬 호출** 연결 |
| 대안 | 사용자 발화 **이미지** 엔티티 블록 → **스킬 호출** |

플러그인 사용 시:

1. 파라미터 이름 예: `secureimage`
2. 해당 블록 출력 → **스킬 사용** → 위 URL 스킬 선택
3. 학부모에게는 **「사진 보내기」 버튼**으로 안내 (채팅창 직접 사진만 X일 수 있음)

### 4. 「첨삭 받기」「피드백」 발화

이 문구들을 **사용자 발화 블록**으로 만들고, 반드시 **같은 스킬 블록**(또는 사진 보내기 블록으로 이동)에 연결하세요.

지금은 **폴백(fallback) 블록**으로 가서 「이해하기 어려워요」만 나오는 상태로 보입니다.

### 5. 폴백 블록

시나리오 **폴백**에 스킬을 연결하지 말고, 위 3·4번 블록으로 유도하는 짧은 안내만 두세요.  
(「예진샘이 순차적으로 답변」 문구는 우리 서버와 무관합니다.)

---

## 학부모 이용 순서 (연동 성공 후)

1. 채널에서 봇 대화 시작
2. **등록된 휴대폰 번호** 입력 (관리자에 미리 등록된 번호)
3. **「사진 보내기」/이미지 보안전송**으로 워크시트 제출
4. 「사진을 받았어요!」 응답 확인 → 관리자 **피드백 대기** 탭에 표시

---

## 서버 쪽 확인

Railway **Deploy Logs**에서 `Kakao webhook POST` 로그가 찍히는지 봅니다.

- 로그 **없음** → 오픈빌더가 스킬 URL을 안 부름 → 위 체크리스트 재설정
- 로그 **있음** + 관리자에 없음 → 전화번호 미등록·이미지 URL 파싱 문제 (최신 코드는 `secureimage` 지원)

---

## 참고

- 카카오디벨로퍼스 **「카카오톡 채널 웹훅」**(친구 추가/차단)은 **사진 수신과 무관**합니다.
- 사진·메시지 수신은 **오픈빌더 스킬 서버** 경로만 사용합니다.
